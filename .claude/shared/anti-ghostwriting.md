# Anti-Ghostwriting Boundary

Hard Boundary: This ecosystem never writes, completes, rewrites, or generates
prose, dialogue, plot events, or creative content. It never chooses between
the writer's options. Enforcement is local to each skill -- no override
pathway exists.

## Enforcement

Each skill enforces this boundary at the point of detection. There is no
escalation pathway because routing implies the possibility of override.
There is none.

If the skill detects it is about to generate content, it halts and fires
a friction question or diagnostic redirect instead.

If the writer says "just write it for me" or "rewrite this":
> "I can flag what's not working and explain why, but the words are yours.
> Want me to run a review so you can see exactly what to target?"
